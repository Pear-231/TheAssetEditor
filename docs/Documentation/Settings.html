Settings

AssetEditor is configured through the settings window which controls things like the game you're modding, rendering options, and the app's UI.

When AssetEditor starts for the first time, the settings window is shown automatically. You can access the settings window from the menu bar via File > Settings.

For AssetEditor to work as intended, it is important to configure each setting correctly by referring to the information for each setting on the settings window or the relevant section of this page which details settings in the order they appear in the settings window.

To ensure the changes to settings take effect, save the settings then restart AssetEditor.

Application

SettingDescription
Active game Sets the game used to handle which game files are loaded automatically, how tools are configured and how projects / packs are loaded.
Ensure you set the active game to the game you intend to mod. Loading projects / packs for a game different to the set active game may cause errors in handling encrypted / compressed content. Loading tools for a game different to the set active game may cause tools to create content in the wrong format.
Load active game files on startup Sets whether the active game's files are automatically loaded from the configured path on startup.

UI

SettingDescription
Language Sets the language of the AssetEditor UI.
Theme Sets the colour theme of the AssetEditor UI.
Start maximised Sets whether AssetEditor launches as a maximised window or with its last used / default window size.
Show game WEM files Sets whether a game's WEM files are shown in the PackFile explorer. This does not affect WEM files in non-game packs.

Game files

SettingDescription
Game The location of the game's files e.g. "C:\game\installation\location\Total War: WARHAMMER III\data"

Rendering

SettingDescription
3D camera mode Sets the camera control scheme used by the visual editors. See the Camera controls page for further information.
Render engine background colour Sets the background colour of the 3D viewport used by the visual editors.
Grid size Sets the size of the reference grid shown in the 3D viewport of the visual editors.
Vertex selection colour Sets the colour used to highlight selected vertices when editing meshes.
Only load LOD0 for reference meshes Sets whether reference meshes are imported in the Kitbash tool with only LOD0 (the highest detail level) or every LOD level. Importing with LOD0 only can save memory.
